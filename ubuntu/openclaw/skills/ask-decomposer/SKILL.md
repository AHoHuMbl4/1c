# Ask Decomposer (К8)

Слой **снаружи** `serene_ask`: для составных вопросов (два периода, сравнение
«больше/меньше», «топ-N и сколько у каждого») разложить на простые подвопросы,
позвать `ask_1c` по каждому, собрать **посчитанные базой** числа и свести ответ
**кодом** — не «в уме» у модели (п. 19 `TARGET.md`).

Контракт исходов A/B/C и люк остаются в `serene_ask` — скилл их не дублирует.

## Когда включать

Сразу, если вопрос явно:

- сравнивает **два периода** («в этом месяце больше, чем в прошлом?», «неделя
  лучше прошлой?»);
- просит **топ-N и число по каждой** позиции;
- перечисляет **несколько независимых срезов** одним предложением.

**Не** декомпозировать простые вопросы — один вызов `ask_1c` без этого скилла.

Решение «составной или нет» принимает **модель** при разбитии (см. ниже), не
списки слов в коде (`HOW_NOT_TO §3.96`).

## Шаг 1 — разбитие моделью

Сформируй JSON-план по инструкции движка (промпт `split_prompt` в
`{baseDir}/decomposer.py`). Каждый атом — **самостоятельный** простой вопрос
со своим периодом, без местоимений на соседей.

Пример для «в этом месяце продали больше, чем в прошлом?»:

```json
{
  "composite": true,
  "synthesis": "compare",
  "atoms": [
    {"id": "mtd", "question": "сколько продали в этом месяце?", "label": "этот месяц"},
    {"id": "prev", "question": "сколько продали в прошлом месяце?", "label": "прошлый месяц"}
  ],
  "compare": {"left_id": "mtd", "right_id": "prev", "relation": "more_than"}
}
```

Если `composite: false` — **не** запускай декомпозитор; один `ask_1c`.

## Шаг 2 — атомы параллельно

Для каждого атома — отдельный `ask_1c` с полем `question` = текст атома.
Параллельные вызовы допустимы. Сохрани `kind`, `text`, числа из `atom` /
`figures` / `atoms`.

`no_data` или `clarify` атома — **честно** покажи человеку; не угадывай (п. 12).

## Шаг 3 — сводка кодом (не моделью)

Запусти движок — он сравнивает/таблицирует **только** уже полученные числа:

```bash
python3 {baseDir}/decomposer.py "ИСХОДНЫЙ ВОПРОС" --plan '<JSON плана>'
```

Или из Python (тесты, оркестрация):

```python
from decomposer import handle, parse_split_plan, make_http_ask_fn

plan = parse_split_plan(<json от модели>)
result = handle(question, lambda _: plan, make_http_ask_fn())
# result.text — сводка; result.atoms — ответы по атомам
```

Сравнение «больше/меньше/равно» — арифметика `compare_values` в
`decomposer.py`, не рассуждение модели. Разница двух периодов = `left − right`
из ответов `/ask`.

## Ограничения

- Скилл **не** разбирает сущности, периоды и меры — это работа `serene_ask` на
  каждом атоме.
- Не подменяй отказ атома догадкой.
- Не считай суммы/разности «из головы» — только из полей ответа `ask_1c`.
- Установка в живой контур бота — только по указанию владельца; в репо лежит
  эталон в `ubuntu/openclaw/skills/ask-decomposer/`.
