# Почтовый приёмник (`ubuntu/mail/`)

Задача: в компании часть писем автоматически пересылается на внутренний сервер,
далее (отдельный трек, не этот) OpenClaw читает эти письма и обрабатывает.

## Устройство

```
почтовый сервер компании (Exchange / Яндекс 360 / Google — правило пересылки)
  │  SMTP, 25/tcp
  ▼
Postfix  →  ai@<MAIL_DOMAIN> (и любой *@<MAIL_DOMAIN> через luser_relay)
  │  локальная доставка
  ▼
Maildir пользователя aimail  (/home/aimail/Maildir)
  ▲  IMAP 127.0.0.1:143 (только localhost)
Dovecot  ←  OpenClaw (чтение ящика — отдельная задача)
```

- Только приём и хранение. Исходящей почты, релея, SASL, смарт-хостов нет.
- Open relay не получается: Postfix принимает только домены из `mydestination`.
- IMAP слушает только localhost — читающий слой живёт на этой же машине.
  Если OpenClaw окажется на другом хосте, добавляется 993/tcp с сертификатом
  (тогда это фиксируется здесь отдельной правкой).
- Секреты: `/etc/1c-mail.env` (`MAIL_USER`, `MAIL_PASSWORD`, `MAIL_DOMAIN`),
  `640 root:1c-secrets` — общая конвенция проекта, OpenClaw-слой читает через
  группу `1c-secrets`.
- Письма доступны и напрямую как файлы Maildir — для слоя, которому IMAP не нужен.

## Установка (владелец, root)

```sh
sudo sh /srv/1c/ubuntu/mail/install-mail.sh [MAIL_DOMAIN]   # умолчание ai.1c.local
```

Идемпотентно. Ставит пакеты `postfix` + `dovecot-imapd`, заводит пользователя
`aimail`, пишет drop-in `/etc/dovecot/conf.d/99-1c-mail.conf`, настраивает postfix
через `postconf` (без шаблонов конфигов), в конце сам шлёт smoke-письмо и
проверяет, что оно легло в Maildir.

## Приёмка

1. Установка завершилась строкой `OK: письмо лежит в ...` (smoke встроен в скрипт).
2. Внешняя доставка (с другой машины в сети):
   `swaks --to ai@<MAIL_DOMAIN> --server <ip-сервера> --from test@test` —
   письмо появляется в `/home/aimail/Maildir/new/`.
3. Чтение по IMAP (пароль из `/etc/1c-mail.env`):

   ```sh
   python3 -c "import imaplib; m=imaplib.IMAP4('127.0.0.1',143); \
   m.login('aimail','<MAIL_PASSWORD>'); m.select('INBOX'); \
   print(m.search(None,'ALL'))"
   ```

4. `systemctl is-active postfix dovecot` — оба `active`.

## Сторона компании (настройка пересылки)

Не часть этого сервера: на почтовом сервере компании заводится правило
пересылки выбранных писем на `ai@<MAIL_DOMAIN>` (адрес сервера — его IP/DNS
в сети компании). Для прод-контура (LXC на компанию, `docs/PLAN_PROD_LXC.md`)
место этого компонента — открытый вопрос §7 того же плана.

## Границы

- Чтение и обработка писем OpenClaw — **не** этот трек: здесь только ящик
  и точки доступа к нему (IMAP + Maildir).
- Фильтрация «какие письма пересылать» — правилом на почтовом сервере компании,
  здесь принимается всё, что пришло на домен.
