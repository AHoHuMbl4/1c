## ПЛАН ВОЛН (каждая = cursor-agent + красная ×3, до ACCEPT ×3)

- **C-канон (design-c.md + красная ×3 на дизайн)**: карта ВСЕХ мест, где вопрос
  может умереть до меню/ответа (bm25-топ-3 в entity-поиске z06; пороги среза
  кандидатов; словарное покрытие; склеенные/разделённые имена; любой no_data при
  непустом пуле). Каждый исход: (а) кандидат проходит в общий тракт; (б) пул идёт в
  LLM-резолвер. Третьего («тихий отказ») НЕТ. Красная проверяет одноканальность:
  не появился ли новый «выбиратель»/обход.
- **C1. LLM-резолвер «где что» — ОДНА точка тракта** (по образцу
  llm_option_highlight из D4: дешёвая модель, ≤800 мс, fail-soft — меню/отказ не
  блокирует; вход: вопрос + кандидаты с подписями/данными, без сырых имён машин,
  п.16; выход: ранжирование/выбор или «кандидатов нет»). Встраивается до меню
  мер/сущностей, один раз — НЕ в каждую ловушку отдельно.
- **C2. Поиск без молчаливых срезов**: слабый/неоднозначный топ → полный пул в
  резолвер → меню с дайджестами. Приёмка: «сколько у нас вообще клиентов сейчас»
  = 361.
- **C3. Незнакомое слово ≠ отказ**: вне словаря → резолвер по описаниям/алиасам
  словаря → меню; слово в журнал (корм шага 7 словарной линии; словарь руками НЕ
  правится). Приёмка: «наторговали» ×2 / «наотгружали» / «вышло» = 357 393,03 /
  0,00 / 661 458,38 / 2 083 550,46.
- **C4. Единая норм-функция имён на ВХОДЕ entity-поиска** (класс _homonym_norm из
  D2 поднять на вход z06). Приёмка: «Сколько движений в регистре реализации ТМЦ?»
  = 80 173.
- **C5. Замки + приёмка**: замок «один путь» на фикстурах всех 6 вопросов (вопрос
  доходит до меню/ответа; no_data только при пустом пуле ПОСЛЕ резолвера);
  регресс 67-вопросного прогона (wrong 0; отказы только честные); живые пробы на
  окне; p95 фронта (резолвер ≤800 мс, меню всегда уходит). Итог: 6/67 → 0.

## ЖЁСТКИЕ ПРАВИЛА (нарушение = дефект волны)

1. **Только сервер ОКНА**: `ssh -i ~/.ssh/id_ed25519_deploy -p 2202
   root@gpu-erw.timpul.pro`. Никаких других машин/баз.
2. **Только АГЕНТЫ/АРМИЯ**: исполнители — исключительно `cursor-agent -p
   "$(cat .claude/state/prompt-<id>.md)" --force --model auto --output-format
   stream-json | tee .claude/state/cursor-run-<id>.log`, фоновым Bash,
   timeout 2400; 1 задача = 1 процесс. Промты — ТОЛЬКО файлами. Красная ×3 на
   КАЖДЫЙ дифф, круги до ACCEPT ×3 (замер живыми прогонами — критики запускают
   замки сами). Приёмка — только замерами оркестратора + живыми пробами.
3. **Один путь**: никаких точечных механизмов под классы вопросов (тема-гейты,
   выбиратели по словам). Незнакомое слово/слабый топ — через общий тракт и

   руками; ничего не подстраивается под окно. Решение обязано работать на
   незнакомой базе.
5. **Промты — не правила**: долженствования в строках для модели ловит гейт;
   в комментариях кода писать описательно.
6. **git-ритуалы**: add и commit РАЗНЫМИ вызовами (гейты снайпера/graph читают
   индекс ДО цепочки); пат-спек `git commit -m "…" -- <файлы>`; «Числа:/Доки:» в
