## КОСЯКИ ДНЯ (оплачены — не повторять)

- **Снайпер коммита**: `git add` ОТДЕЛЬНЫМ вызовом перед commit (упало
  4 раза за день!). В сообщении коммита НЕ писать `git … -- файлы`
  («ДИФФ НЕ СНЯТ»).
- **Граф MCP**: наблюдение вешать НА ТОТ компонент, что правится
  (упал на deploy_wiki_alias.sh, влепил в promote). mcp-memory.json
  пишется на диск с задержкой: add_observations → sleep 3 → git add;
  если гейт «граф не в коммите» — файл на диске новее индекса, ре-add.
- **Фоновые циклы внутри Bash-вызова с `&` УМИРАЮТ вместе с вызовом**
  (наблюдатель добора). Наблюдатели — отдельным фоновым вызовом Bash
  (run_in_background=true, disable_timeout=true).
- **Юнит, стартовавший ДО деплоя, работает СТАРЫМ кодом** (collision-3
  снова сломался). Порядок всегда: стоп юнита → деплой → чистка → старт.
- **BATCH=1 протёк в collision/reask через общий LIMIT :batch** — при
  любых правках размера пачки проверять ВСЕ сайты вызовов. Групповые
  фазы (collision/reask) ≠ «1 задача = 1 вызов» (COLL_BATCH=8).
- **SSH-кавычки**: SQL/JSON — только файлами (scp + psql -f). Вложенный
  кавычек в одинарной ssh-строке = мусор. psql-вывод: -At -F
  "$(printf "\t")" (двойные ВНУТРИ одинарных работают); \pset tuples_only
  даёт выровненные «|» — не годится.
- **python3 -c многострочник** — ложные ошибки; только heredoc-файлом.
- **/tmp**: чистится (tsv-эталоны не живут); имена могут быть заняты
  чужими правами (q2.sql root 27.07 — Permission denied) — менять имя.
- **Прогнозы не экстраполировать по короткому окну** (владелец справедливо
  спросил «ты говорил час!»): слова collision имеют разную стоимость;
  давать диапазон, скользящую оценку по наблюдателю.
- **Промты перед запуском вычитывать** (иероглифы-артефакты глотались).
