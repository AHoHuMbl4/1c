2026-07-26. Владелец: «ты сам решил это. сам сделал неправильно… это важное решение.
я не говорил что плохо с базой на винде». До этого дважды: «почему ты не посоветовался со мной».

**Что произошло:** в проекте был проверенный эксперимент — PostgreSQL на Windows рядом с 1С
+ `postgres_attach` + индекс на VIEW (данные у клиента на Windows, на Ubuntu только индекс;
docs/INSTALL_LOG.md, коммиты 16f133d, 334eb5d, 25 июля 2026). Я строил полную загрузку по
переписи и молча расширил другой путь — CSV прямо в SereneDB на Ubuntu (полная витрина
226 таблиц). Выбор режима размещения данных не поднял как вопрос.

**Why:** архитектура размещения данных клиента — граница доверия и продукта, это уровень
владельца. Существование пути в коде не делает его выбор согласованным.

**How to apply:** любое решение, меняющее ГДЕ лежат данные / КУДА они копируются / ЧТО
уходит наружу — только через явный вопрос владельцу с фактами и ценой вариантов, ДО
написания кода. Даже если «так уже было» — масштабирование пути = выбор пути.
Связано: [[feedback-no-hardcode]], решения по серверу — только по явному указанию.
