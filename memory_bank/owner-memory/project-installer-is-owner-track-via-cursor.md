> «Установщик я делаю отдельно через Cursor.»

**Что это значит для сессий:**

- Работа по п. 14 контракта (инсталлятор) ведётся **владельцем лично**, в Cursor,
  параллельным треком. Очерёдность «делается в конце» скорректирована самим владельцем —
  это его право; сессии эту очерёдность больше не сторожат.

  не дефект и не находка**: коммитит их владелец сам, когда решит. Сессиям каталог
  не трогать и тревогу по нему не поднимать.
