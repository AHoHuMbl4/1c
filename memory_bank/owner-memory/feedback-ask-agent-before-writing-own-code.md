2026-07-26. Владелец, дословно: «агент для чего блин!!! это нативная штука serene!!!!!!!»
Прервал меня прямо на инструменте: я начал писать СВОЙ CTE-запрос для отбора кандидатов-
сущностей, вместо того чтобы спросить `serenedb-native`, как это делается штатно.

До этого он же: «кажется, что не используется serene полностью — её функционал, и ты
изобретаешь велосипед». Прогон агента подтвердил: probe() (мой UNION ALL из 144
подзапросов), match_expr() (мой цикл по k вместо ts_compound), ts_like вместо
sparse_ngram, три скорера вместо пяти — всё это штатное, которое я писал заново.

**Why:** у них проверено на 1653 тестах и на больших данных, у меня — гипотеза, которая
разваливается на масштабе (мой отбор кандидатов упирался в предел argv на 1900
сущностях). Агенты созданы ровно для этого вопроса; писать своё, не спросив, —
двойная работа и худший результат.

**How to apply:** ЛЮБАЯ строчка своего SQL/алгоритма поверх SereneDB → сначала
`serenedb-native`. Поверх OpenClaw → `openclaw-native`. Своё писать только после
прямого ответа агента «штатного механизма нет». Это относится и к «мелким» правкам:
велосипед начинается с одной удобной функции.
