## SereneDB 26.07.3 — что важно знать

**Настройки по умолчанию** (менять осознанно):
```
sdb_ivf_posting_size = 1024   sdb_nprobe = 8        threads = 6
sdb_ivf_sample_factor = 0     sdb_rerank_factor = 4 memory_limit = 50 GiB
sdb_scored_terms_limit = 1024 (молча усекает ранжирование широких запросов)
```

**Ловушки, проверенные замером:**

| Что | Суть |
|---|---|
| `quant` по умолчанию `none` | с `metric='cosine'` квантизация **запрещена вообще**; работает только с `l2`/`ip` |
| При `quant='none'` нет переранжирования | точный пересчёт кандидатов не выполняется никогда |
| `ts_regexp` термозависим | на кириллице `догово..` даёт 1678 вместо 565 — молча **неверный** ответ, а не ноль |
| `ts_offsets` в байтах | для кириллицы вдвое больше символьных |
| `WHERE` в `ts_dict_*` | фильтрует **документы**, а не термы |
| Один скорер на запрос | `Only one scorer function is allowed`; обход — `UNION` |
| `USING secondary` | молча создаёт индекс **без колонок** при неизвестном опклассе |
| Сборка `ivf` не отменяется | `pg_cancel_backend` возвращает успех, работа идёт; только рестарт |
| `hnsw` | **удалён из продукта**, есть только в устаревших демках |

**Инструмент, о котором стоит помнить:** `CREATE TEXT SEARCH DICTIONARY zz(help)` —
движок печатает справочник всех шаблонов и опций **именно нашей сборки**. Не нужно
гадать по репозиторию.

**Скореры:** доступны `bm25`, `tfidf`, `lm_jm`, `lm_dirichlet`, `indri_dirichlet`,
`dfi` (три меры) + служебные `raw_*`. В A/B гоняются только три — расширить.

## ⚠ Готчи автоматизации Windows по SSH (сэкономят часы)
- Длинные PowerShell по SSH — только `powershell -EncodedCommand` (base64 UTF-16LE) ИЛИ
  `scp` файла + `-File`. Экранирование bash→cmd ломает `$`/кавычки/кириллицу; лимит cmd ~8191.
- `.ps1` с кириллицей — UTF-8 **с BOM** (PS 5.1 без BOM = ANSI → синтакс-ошибки).
- COM-коннектор: `regsvr32 comcntr.dll` из каталога `bin` платформы; класс `V83.COMConnector`;
  вызывать из **32-битного** PowerShell (`C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe`).
- COM-квирк: свойства (`Metadata`) отдаются только рефлексией; методы коллекций метаданных
  (`Найти`/`Count`) НЕ резолвятся, но **`foreach` по коллекции работает** (так задавали состав OData).
