### Сделано по-штатному

- индекс многополевой: `inverted(doc dict, refs dict, src_table)`; `src_table` без
  словаря = keyword, фильтр **внутри** индекса (подтверждено планом запроса);
- `ts_compound(must, must_not, should, k)` вместо цикла подбора;
- запись корпуса через `MERGE INTO` — механизм движка, в его тестах отдельно оговорено
  поведение с инвертированным индексом на цели;
- инкремент считает **база**: отпечатки во временной таблице, джойн вместо словаря на
  весь корпус в памяти Python (пик 334 МБ → 184 МБ);
- табличная часть определяется контрактом `$metadata` (ключ `[Ref_Key, LineNumber]`),
  владелец найден **по данным**. Проверено на 4585 типах: виртуальные таблицы регистров
  под правило не попадают;
- при неоднозначном вопросе система **спрашивает**, а не угадывает; судья
  неоднозначности — модель, порога в коде нет.
