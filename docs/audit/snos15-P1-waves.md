## Неясно

1. **Collapse-equal / равные числа** (MERGE §4.1; M1 §в.3; M3 §в.2): W4 сносит
   collapse по формуле; финальный вердикт владельца может вернуть «одно число
   без меню» — тогда точечный revert z21, не всей W4.
2. **Coverage-мета** (MERGE §4.2; #15): в W7 не резать без ответа; отдельный
   endpoint vs формула — не зафиксировано.
3. **Граница периода / z02** (MERGE §4.3; §3.4): W5 убирает prefer/majority, но
   оставляет слоты; полная замена intent вики — **не в пакете**.
4. **Один wiki-verify yes при pool>1** (M1 §в.2): волны не вводят «всегда меню
   при pool>1» — это было бы новым правилом; ждём стоп-точку / K.
5. **Axis/grain `decide_grain`** (M1 §в.4): авто-ось частично в W3 через
   rank_axis; полный serene_axis — граница не размечена MERGE §2 отдельным №.
6. **Рантайм vs диск** (M1 §в.10; M2 §в.3): объём `_bootstrap` после W2/W7
   уточняется только живой загрузкой на полигоне — оценка строк W7 по патчу
   (±) не точна заранее.
7. **entity_rank_v2.py**: вырезать файл в W2 или оставить мёртвым до W7 —
   выбор исполнителя; на тракт не влияет после снятия call-site.
8. **Подписи меню до W4:** W1–W3 могут чаще отдавать clarify со старыми
   table-label — допустимый промежуточный дефект формы, не смысла выбора;
   формула по подписям закрывается в W4.
