# Карантин okna-1: хвост seq 195 (2026-08-31)

Окно: LXC **okna** на `gpu-erw.timpul.pro` (ssh `-p 2202`). DSN: `host=127.0.0.1 port=7890 user=postgres dbname=postgres`. Только чтение: `state.json`, `manifest.json`, `journalctl -u 1c-packet-apply`, лёгкие SELECT. Юниты не трогались.

## Что такое «карантин» технически

Карантин — **не таблица в SereneDB** и не счётчик в витрине. Это **терминальное состояние пакета** в файловом inbox приёмника:

| Место | Путь / форма |
|---|---|
| Состояние пакета | `/var/lib/1c-packet/inbox/<base_id>/<package_id>/state.json` → `"state": "quarantined"`, `"error": "<код>"` |
| Сводка базы | `/var/lib/1c-packet/inbox/<base_id>/state.json` → `packages[<id>].state/error`, `last_applied_seq` |
| Журнал apply | `journalctl -u 1c-packet-apply` → строки `apply QUARANTINE base=… pkg=… code=…` |
| Код | `ubuntu/packet/packet_apply.py`: класс `Quarantine`, запись через `_set_pkg_state(..., "quarantined", …)` (`135:147`, `889:905`) |

Пакет в `quarantined` **больше не берётся** в `_iter_verified` (там только `verified`). Повтор apply сам не идёт — нужен ручной сброс состояния (вне scope этого аудита).

Другие коды карантина в коде (`chunk_missing`, `mix_versions`, `delta_without_table`, `contract_tx_failed`) на okna-1 **не встречаются**.

## Разбивка по причинам (код + сущности delta)

Все 19 пакетов падают на **одном** коде приёмника. Различие — только **какая delta-сущность** была первой, на которой apply остановился (порядок в `manifest.json`).

### Таблица 1 — код карантина

| Код | Пакетов | Delta-строк в манифестах | Механизм | Строка кода |
|---|---:|---:|---|---|
| `delta_without_key` | **19** | **4934** | `_delta_delete_clause`: нет `Ref_Key`/`Recorder+LineNumber` в колонках витрины → `raise Quarantine("delta_without_key")` | `packet_apply.py:515-530` |

**Корневая причина (уже починена в выкате):** до `_ci_col` (коммит `30cf7d7`) поиск колонки шёл **с учётом регистра** (`"Ref_Key" in mart_cols`). В витрине okna физическая колонка — **`ref_key`** (замер `duckdb_columns()`). `_ci_col` не находил ключ → ветка регистра (`Recorder`+`LineNumber`) → у документов её нет → карантин.

Сейчас на okna в `/opt/1c-packet/packet_apply.py` **`_ci_col` есть** (строки `489-495`, `517-530`). Пакеты остались в `quarantined` с **28.08** — apply их не перечитывает.
