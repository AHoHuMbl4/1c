Дата среза: 12.09.2026. Только чтение AST; код не менялся.

## 0. Метод

- **Legacy-источник:** `z20_ask_main_http_legacy.py` **после** `_bootstrap._patch_z20_wiki_primary`
  (патч применяется только к legacy при `ASK_ONEPATH≠1`; см. `_bootstrap.py:210-213`).
- **Новый:** `z20_ask_main_http.py` без патча (`ASK_ONEPATH=1`).
- **Внешний символ:** голый `Name` в Load (функция/константа/модуль), который
  **не** определён в том же файле и не builtin. Вызов = `Call(func=Name(...))`.
- Учтены вложенные scope (def/class/lambda/comprehension/for/except/with/walrus).
- **Владелец:** последнее non-z20 определение в порядке `load_all` (`_imports` → зоны → z20).
- Сравнение «мёртвое»: есть в external-множестве legacy, **нет** у нового z20.
  Дополнительно: есть ли ещё Name-Load этого имени в других зонах/`_imports`/`_wire`/`_ctx`
  (не в z20*) — чтобы отделить «не зовёт новый вход» от «нигде больше не читается».
