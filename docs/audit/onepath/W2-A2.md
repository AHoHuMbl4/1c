- **легитимно** — ровно один кандидат **или** выбор человека (меню/`readings_menu`/clarify);
- **выбиратель** — код сам фиксирует прочтение при >1 кандидате (silent pick / model-pick / first-match / score-leader без меню).

Только то, что зонные карты пометили как достижимое из **нового** z20.

### Сводка по выбирателям

| вердикт | число (из таблицы) | действие для «супер простого» пути |
|---|---:|---|
| **выбиратель** (явный) | ≈18 | либо увести в wiki/меню до SQL (план O3 №8–14), либо оставить с замком «ровно один кандидат» |
| **легитимно** | ≈8 | оставить |
| **пограничные / смесь** | ≈4 | решить владельцем на этапе-2 (S3, S12, S25, S27) |

**S1, S5, S8, S10–S11, S14, S19–S20, S24, silent-ветка S25.**
