## 3. Имена из `_imports.py` — что тянут

В runtime (`_bootstrap._seed_namespace`) в общий namespace копируются все публичные
имена модуля `_imports` (имена на `_` не сидятся). Файл зоны также содержит
`from ask._imports import *` — при bootstrap эта строка срезается, эффект тот же
через seed.

### 3.2. Экспорт `_imports`, но в z20 не упоминаются

Символы сидятся в namespace и могут понадобиться другим зонам; для **самого**
текста нового z20 не обязательны:

- `Path` — stdlib pathlib.Path (`_imports.py:11`)
- `contextvars` — stdlib contextvars (`_imports.py:4`)
- `csv` — stdlib csv (`_imports.py:5`)
- `datetime` — stdlib datetime (`_imports.py:6`)
- `io` — stdlib io (`_imports.py:8`)
- `secrets` — stdlib secrets (`_imports.py:17`)
- `subprocess` — stdlib subprocess (`_imports.py:18`)
- `urllib` — stdlib urllib.request (имя модуля urllib) (`_imports.py:22`)

### 3.3. Детали внешних пакетов, к которым z20 ходит через alias

**`ACM` → `ask_choice_mem`**: из z20 только `ACM.split_memory_action` (2× в HTTP
Handler). Модуль также содержит память выбора (`attach_choice_memory`, lookup/upsert),
но новый z20 зовёт их не напрямую — через зональные обёртки `attach_memory_shadow` /
`seal_clarify` / `peek_resolved` (z14).

**`PV` → `partial_visible`**: `PV.ensure_partial_visible(out)` (1× в
`answer_checked`) — дописывает клиенту видимый partial.

**`serene_axis`**: прямо из z20 — `decide_grain` (settle оси), `rank_k` и
`group_rows` (ветка SQL/agg в `answer`); при `ImportError` = `None` → ветки оси гасятся.

**`serene_enough`**: `period_assumed` / `period_given` в `empty_after_period_action`;
при `None` — сразу `no_data`.
