# СНОС-15: ИСПОЛНИТЕЛЬНЫЙ ПЛАН v2 (2026-09-11, после красной волны K)

Формула №15 (владелец, 11.09): вопрос → интерпретация из вики → запрос в базу →
варианты с описаниями из вики (если прочтений >1) → выбор человека → ответ.

ярлыки). Стоп-точка снята 11.09 (решения владельца §7): волны исполняются.

## 0. Правила исполнения (все волны)

1 волна = 1 коммит (пат-спек, код+_bootstrap+замки ОДНИМ коммитом, «Числа:»/
«Доки:», граф тем же коммитом) = 1 выкат (deploy-ask.sh + рестарт) = замер.
Цепочка: правка → офлайн-замки (не pytest) → load_all-замок (импорт без
NameError, diff патча ⊆ снесённое) → полигон :8092 → прод.
Откат: revert волны N валиден ТОЛЬКО до волны N+1 (K3 §6): код+bootstrap+замки
одним пат-спеком, выкат симметричен; частичный возврат z11 без call-sites
запрещён.
СТОП-критерий: Δconfident_wrong > 0 — откат; ИЛИ diag-стоп: kind=answer ∧
(мер >1 / окон >1) ∧ меню не показано — откат, даже если число совпало с
эталоном (скрытый wrong, K3 §3). Сущностный «pool>1 без меню» — НЕ стоп
(решение 4-А: один verify-yes = одно прочтение).
match→clarify = НОРМ. no_data при живых данных = дефект п.21.
Резать по МАРКЕРАМ (имена функций/символов), не по номерам строк M-карт —
строки плавают (K2 §2).
