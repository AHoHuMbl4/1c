## Атаки

### Ат1 — Нет численной связки с целями W4 / бюджетом 88с

План даёт профиль 51.7+21.5+12+6–9, но **нет таблицы** «пункт → ожидаемые −сек →
остаток wall на классе „полный отчет“ / „за квартал“». Без неё стоп-точка не
проверяет, закрывает ли набор смерть 88с или только «улучшает молекулы».

**Требование в план:** таблица до/после по каждому пункту 1–4e + Σ и явная цель
(например: меню-класс ≤20с через A2; полный путь K6≤10с + post-K6≤2с → префикс
к A &lt;40с; «квартал» — fork −≥40%). Числа — из M4 R1–R7, не новые фантазии;
пометить гипотезы (stock#2 до E8).

### Ат2 — Двойной счёт выигрышей A2 ∥ K6 на меню-вопросах

На классе, где A2 срабатывает, K6 **не запускается** (§1). Тогда −сек от п.3 на
этом классе = **0**. Если в сводке сложить «A2 −60…80» + «K6 −42» как независимые
на одном и том же Q — бюджет врёт. K6-выигрыш живёт на путях, где A2 fail-closed
молчит (lock/wiki/одна ветка/полный отчёт без меню).

**Требование:** два столбца эффекта — «меню-класс (A2)» и «полный путь (не-A2)»;
запрет суммировать оба на одном Q; в приёмке п.3 мерить на Q, где A2 *не* взял
путь (иначе замер K6 пустой).

### Ат3 — L67 для A2: ослабление и группировка

A2 = меню **без** K6/not_for/live counts (M4 Ат4). Это не тот же риск, что B/A
после полного префикса. План §1(г): «L67 группы A2+B+A»; общая приёмка: «L67 после
групп A2 и после п.3/п.4 (wrong ≤3)».

Дыры:

1. **Свой L67 на A2 обязателен** — в плане намечен, но не разведён от B/A:
   отдельный набор Q, где baseline — post-K6 A fingerprint, не «общий clarify».
2. **Одной группы A2+B+A мало**, если A2 режет качество ветками-призраками, а B/A
   это не ловят (разные точки входа). Минимум: **L67-A2** (fingerprint+wrong на
   меню) **отдельно** от **L67-ранг** после п.3 и узкого zone после 4c; совместный
   прогон A2+B+A — доп. регрессия «не сломали чужие пути», не замена.
3. Порог wrong≤3 без размера выборки и списка эталонных Q — декорация.

### Ат4 — Психология выката: «7 пунктов → одним окном»

§ приёмка: «финал — выкат одним окном после стоп-точки». § откат: «каждый пункт —
отдельный коммит». Внутреннее противоречие: коммиты атомарны, выкат — пачкой.

Риск: после «да» владельца выкатывают 1+3+4a–4e разом; при L67-регрессии неясно,
какой пункт виноват; откат «всего окна» дороже пошагового.

**Требование M4-совместимое:** полигон — строго по шагам с замером между
(тайминги 3 классов + замки + L67 группы шага); бой — **пофайлово/попунктово**
(минимум: A2 отдельно → K6 отдельно → хвосты по одному); «одно окно» допустимо
только как *календарное* окно выката, не как один atomic deploy без промежуточных
замеров. Сейчас формулировка «одним окном» **подталкивает к плохому**.

### Ат5 (доп., из M4) — E8 в плане ужежен

M4 E8 = субмаркеры stock#1/expand/features/stock#2 + доказательство 52+21.
План §2 = EXPLAIN индекса search_idx. Это **другой** E8 (вход для п.3), не
атрибуция молекулы-2. Без субмаркеров 4c может чинить не ту дыру (contention такта,
M4 Ат1). **Требование:** вернуть E8-атрибуцию 21.5с *или* явную зависимость
«4c только если EXPLAIN/TRACE показал stock-тело».

## Требования к стоп-точке (что показать владельцу)

Презентация стоп-точки — **один экран/одна страница**, без внедрения до «да»:

1. **Свод −сек по пунктам** (таблица Ат1): пункт | класс вопросов | −сек (min/max) |
   остаток до 88 / до цели A | статус гипотеза/замер. Два класса минимум: меню
   (A2) и полный путь (K6+хвосты). Итог: «закрывает ли набор смерть отчётных /
   квартальных — да/нет/частично».
2. **Порядок** одной строкой с зависимостями: A2∥(E8→K6→4c); 4a/4b/4d после;
   4e последний; C/D вне/после. Явно: что на полигоне до стоп-точки, что только
   после «да».
3. **Риски** коротко: A2-меню без live (п.12); L67 ранг после K6; stock-атрибуция
   до E8; двойной счёт; такт vs ask (contention). Контрмеры уже в плане — одной
   колонкой.
4. **Откат:** пункт = коммит; revert+рестарт ask; что мерить после отката
   (тайминги без L67). Запрет выката «всем окном без промежуточного замера».
5. **Запреты** списком из §5 + недостающие из M4 (fork off; SAMPLES; deadline;
   ThreadPool; A2 без fingerprint; не лечить K6 psycopg).
6. **Вопрос владельцу:** утвердить порядок и скоуп (A2+K6+хвосты vs только A2 на
   неделю) — не «утвердить текст плана как есть».

## Вердикт

**Доработать** перед стоп-точкой. План не ложный и не расходится с M4 по ядру
(A2+fingerprint первым по смыслу, E8 перед K6, хвосты атомарны, psycopg последний,
4 запрета на месте), но к показу владельцу неполон.

### Минимальный список допила

1. Таблица «пункт → −сек → остаток» по двум классам вопросов; запрет двойного счёта
   A2+K6 на одном Q.
2. Явная позиция по stock-skip: либо вернуть шаг «после E8, до K6» на полигон,
   либо обосновать 4c-после-K6 + обязательная E8-атрибуция 21.5с.
3. L67: отдельная группа A2 (fingerprint≡A) ≠ совместный только A2+B+A; размер
   выборки/эталонные Q.
4. Выкат: заменить «одним окном» на пошаговый бой с замером между пунктами;
   «окно» = календарь, не atomic blob.
5. §5: дописать запреты M4 — `ASK_FORK_DETECT=0`, не лечить 52с транспортом,
   не калибровать IN под okna как единственный фикс, не трогать такт/B в скоупе.
6. Развести E8-EXPLAIN(индекс) и E8-TRACE(субмаркеры 52/21) — сейчас имя одно,
   смысл сужен.

После пунктов 1–4 стоп-точка осмысленна; 5–6 — дешёвая страховка от уже известных
ловушек M4.
