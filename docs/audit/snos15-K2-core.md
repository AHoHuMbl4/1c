### Early-A не становится «главным меню» (волна 5)

После сноса цикла PLAN пишет: A-clarify — главное меню при >1 src.
Факт кода (`z20:3608–3665`):

- вход только при `len(arb_pool) > 1`;
- `_ec_allow = _ec_composite or _ec_src_ambig` — **узкий** допуск;
- `_ec_ban` включает `trusted`, locks, **`_ec_wiki`** (wiki verify == pick),
  `writer_pair`, one_src, same_fam_no_atoms, sales_cold.

При верифицированном вики-лидере `wiki_arbiter_locked` схлопывает
`arb_pool` в `picked` (`:3245–3248`) — A не нужен (ок).

Но после волны 5 (снос doubt/writer/signals) `arb_pool ≈ picked`. Меню
остаётся на `len(picked) > 1 → mk_opts :3920`. Случаи, где раньше арбитр
делал diverge-clarify по **сопернику не из picked** (writer_pair /
stop2), **исчезают без замены** — либо тихий ответ по одному pick, либо
вообще нет меню. «Перенести diverge на mk_opts» в PLAN **не закрывает**
этот класс: mk_opts смотрит `picked`, не старый `arb_pool`.

Дополнительно: `_ec_composite` зовёт `sales_rank_engaged` (`:3619`) —
после волны 2 без переноса классификатора это `NameError` ещё до меню.
