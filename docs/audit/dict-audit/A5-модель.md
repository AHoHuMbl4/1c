## Вердикт

Генератор зовёт **не** агента с tools, а `openclaw infer model run` через
`alias_infer_gateway.py`. Имя модели в коде по умолчанию —
`vllm/Qwen3.8-27B`; с **06.09** канон сети для словаря — **OpenRouter
`qwen/qwen3.8-27b`** под тем же provider-id `vllm` (NETWORK.md). Temperature
в вызов **не передаётся**; thinking — `off`; `maxTokens` каталога — **8192**.
Пределы модели на практике: обрезка JSON (пачка 20), RPC-шлюз 120 с
(обходён `--local`), пустышки при осечках/правах, биллинг облака, коллизии
без сходимости без `search_alias_probe`.

## 5. Альтернативы (факты; **не переключать**)

| Критерий | Агент OpenClaw бота (DeepSeek) | Локальный 27B `gpu-27b` / `10.3.1.12:8000` | OpenRouter `qwen/qwen3.8-27b` (текущий канон словаря) |
|---|---|---|---|
| Роль в контуре | primary чата / tools (`PIPELINE`: агент main) | ask + исторический словарь; поднимает владелец | словарь с 06.09 (NETWORK) |
| Контекст | каталог flash: `contextWindow` 1_000_000; накладные агента ~**3576 in** + payload | живой `max_model_len` был **16k**, с 23.08 контекст **64k**; в openclaw.json шаблон 131072 ≠ факт инстанса (HOW_NOT_TO) | тот же family 27B; смоук пачки мал |
| Русский / JSON словаря | pro: wiki measures coverage **100%**; flash **50%** — flash отклонён (§3.81) | С1 okna: валидные RU алиасы, пустых 0 | смоук: валидный JSON с ролями клиентов/поставщиков (CHANGELOG 06.09) |
| Детерминизм | `--thinking off` обязателен для pro; `high` отклоняется; temperature не задаётся генератором | `enable_thinking:false` в клиенте **не выключал** рассуждения (замер 26.08); temperature не задаётся | то же: temperature не в CLI; скорость выше, детерминизм API не гарантирован |
| Надёжность | billing/402 ломает пачки (`wiki-alias-try.log`) | процесс/GPU могут быть down (23.08 :8000 отсутствует) | pay-as-you-go; зависит от кредита владельца |
| Скорость пачки | агент+tools тяжелее; не канон словаря | ~**17 мин**/20 сущ. local | смоук **18,5 с**/2 сущ.; полный OR-прогон в CHANGELOG не замерен |
| Стоимость | платный egress | **$0** при живом GPU | кредит OR |
| Пригодность для словаря | отвергнут как основной путь: flash слабо на measures; pro дорого; ушли на infer без tools | качество доказано; узкое место — latency и аптайм GPU | быстрый транспорт при живом ключе; модель та же линейка Qwen3.8-27B |

Итог сравнения: для **генерации словаря** нужен длинный структурированный JSON
без tool-surface → путь `infer model run --local` уместен. Сила модели важна
(flash отвергнут замером). Транспорт сейчас выбирается между «бесплатно, но
медленно/зависимо от GPU владельца» и «быстро за кредит OR» — без смены id
семейства в умолчании скрипта.

## Вывод

1. **Модель словаря** — семейство **Qwen3.8-27B** через provider `vllm` в OpenClaw;
   id в скрипте `vllm/Qwen3.8-27B`, на окне с 06.09 проводка на **OpenRouter
   `qwen/qwen3.8-27b`** (NETWORK/CHANGELOG). Вызов — `alias_infer_gateway.py`
   → `infer model run --local`, thinking off, без temperature.
2. **Пределы** не в «глупой модели», а в **длине JSON** (8192 out / пачка),
   **транспорте** (gateway 120 с), **инфре** (права temp, аптайм GPU, биллинг)
   и в **сходимости коллизий** без probe / при `COLLISIONS=0`.
3. **Полный прогон** на okna исторически часы wall; одна local-пачка ~17 мин;
   OR ускоряет смоук, но полный OR-прогон и живой `collision_left` окна здесь
   не замерены — нужна сессия с доступом к SSH/psql окна.
4. **Альтернативы:** DeepSeek-агент — другой контур и отвергнут для measures;
   локальный 27B — эталон качества/$0 при живом GPU; OR — текущий быстрый
   транспорт той же линейки. Переключение в этой задаче не предлагается.
