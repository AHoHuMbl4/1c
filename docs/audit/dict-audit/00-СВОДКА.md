## Системные дефекты (каждый ≥2 агентами)

1. **Словарь не про речь людей**: люди говорят глаголами-событиями и склейками
   («наторговали», «реализациятмц»), словарь — именами и ролями. Промт прямо просит
   «title itself» → повторы имени; мета-ярлыки 1С («список/справочник/типы») — в
   синонимах. (A2, A3, B3, B5)
2. **Промт не просит главного**: нет лимита/запретов (падежи, латиница, мета-слова,
   слова соседей), нет «сомневаешься — не пиши», нет тематического doesNotAnswer
   (NEF = соседские редиректы, 96%), few-shot один английский. (B5, A1)
3. **best_used_for врёт в ключевых местах**: «установка цен» у Номенклатуры повлекло
   прайс-wrong (why судьи дословно: «standard entity for storing price list items»);
   ~15% канцелярит/повторы. (A4, B4)
4. **MERGE душит обновления**: первый проход пишет только в ПУСТЫЕ поля; обновить
   BUF/NEF живой строки может только коллизионный круг (полная перезапись). Улучшенный
   промт НЕ обновит уже заполненный словарь без force-режима. (B1)
5. **Обрезки конвейера**: parse [:900]; str_split по запятой ломает фразы со скобками
   (30 строк nef); паспорт 1500. (B1)
6. **Детерминизм**: temperature не передаётся; перезапуск даст другой словарь;
   13 коллизий не сведены до сходимости. (A5, B5)
7. **Универсальность (п.0)**: локаль стемминга ru_RU по умолчанию (чужая база —
   BOXED_BLOCKERS §2), CAP=100/такт и batch=20 (база 1500 сущностей = 16+ тактов),
   слепота стемминга на склеенных именах («номерабсо»). (A6, B6, B2)
8. **Модель**: qwen3.8-27b (OpenRouter с 06.09), thinking off, maxTokens 8192;
   пачка 20 сущностей, обрезки JSON. (A5)

## Проект улучшения (общие правила, не под вопросы) — на стоп-точку владельцу

1. **Промт генератора v2**: синонимы = только слова из вопросов людей + ролевые слова
   по flows; ЗАПРЕТ: мета-ярлыки платформы (список/справочник/типы/виды/каталог/
   реестр/журнал/документ), падежи одного слова, латиница, слова соседей;
   bestUsedFor = 2–4 коротких вопроса-шаблона без чужих тем; notEnoughFor =
   тематическое «не я» + сосед отдельно; «сомневаешься — не пиши»; few-shot на языке
   базы. (Генератор данных, не персона бота — гейт check-prompt-rules не про него.)
2. **Кодовый фильтр мета-слов** после генерации (универсальный стоп-словарь
   служебных слов платформы 1С — не привязка к базе).
3. **Force-перегенерация**: окно перезаписи живых строк (WIKI_ALIAS_FORCE=1), иначе
   новый промт не обновит словарь.
4. **Склейки имён**: раздельные формы рядом со склейками (генератором) + вопрос к
   докам SereneDB о штатном ngram/compound для стем-словаря.
5. **Приёмка генератора** — универсальной метрикой на живом журнале вопросов
   (метод A3/B2): покрытие/каша до-после; не L67.
6. Наблюдаемость генератора: счётчики (синонимов отброшено, коллизий сведено).

Порядок: 1–3 на песочнице (alias_okna_c5) → метрика A3 до/после → стоп-точка →
перегенерация боевого словаря.
