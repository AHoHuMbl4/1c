## 0. Инвариант (единственный)

вопрос → интерпретация из вики → запрос в базу → варианты с описаниями из
вики (если прочтений больше одного) → выбор человека → ответ. Ничего больше.

- «Прочтение» — любого рода: сущность, мера, окно, ось. >1 → меню из вики.
- Одно прочтение → сразу ответ. Простой счёт строк (count) — мера НЕ
  спрашивается (count не прочтение).
- **Люков нет. Вторых чисел нет. Исключений нет. Обходов вики нет.**

  построителем меню; в ответе ровно одно число (без «снятий допущения»).
