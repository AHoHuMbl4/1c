# Опись полноты okna-1

_Снято 18.08 по юниту `167.233.249.110` (только чтение). Витрина восстановлена
полностью 15.08; агент в режиме дельт. База файловая на Windows — доступ у
владельца есть._

Ответ на вопрос «что ещё не дошло»: **ничего сверх названного**. Каждая
сущность контура попадает ровно в одну из трёх корзин (доехала / закрыта /
пуста). Арифметика сходится до единицы; пересечений между корзинами нет.

Поимённые списки — приложения в [`completeness-okna/`](completeness-okna/).

## 2. Причины пропусков

Все **35** закрытых — **`no_read_right`**: HTTP 401, код 20 («нет роли
Чтение»). Источник — поле `error` каждой записи в `skipped.json`
(`updated_utc`: `2026-08-17T14:38:01Z`). Других причин (`not_published`,
`rls_filtered`, таймаут, память) в снимке **нет**.

| Причина | Сущностей |
|---|---:|
| `no_read_right` / HTTP 401 код 20 | **35** |

Механика — та же, что klient-1: шаг 14 установщика не открыл чтение на объекте;
агент пробует закрытые каждым тактом, пока 1С не отдаст строки.

## 3. Реальная потеря

Из **35** закрытых вычитается то, чьи данные **уже есть в витрине** под другим
именем (сёстры `_RecordType`, проекции).

| Что вычитаем | Число | Почему это не потеря |
|---|---:|---|
| Дочитанные повторно | 0 | пересечение `arrived ∩ skipped` пусто |
| Закрытый `X_RecordType` при доехавшем `X` | 0 | ни одна из двух закрытых пар регистра не имеет доехавшей основной |
| Обратное (закрытый `X` при доехавшем `X_RecordType`) | 0 | — |

```
реальная потеря = 35 − 0 = 35
```

Список — [`completeness-okna/real-loss.txt`](completeness-okna/real-loss.txt)
(35 имён). Это то, чего в базе **нет ни в каком виде**.

## 4. Закрытые домены (35 сущностей)

В klient-1 часть закрытых **типов документов** компенсируется движениями
регистров (`Recorder_Type`). На okna **такой компенсации нет**: по всем
регистрам витрины (58 таблиц с `Recorder_Type`) найдено **38** типов
документов-регистраторов — **ни один** из **16** закрытых `Document_*` в них
не встречается. Список регистраторов — [`completeness-okna/used-docs.txt`](completeness-okna/used-docs.txt).

Закрытые **35** сущностей по смысловым доменам (имена):

| Домен | Сущностей | Что закрыто | Движений в витрине от этих типов |
|---|---:|---|---|
| **ФУРН** (фурнитура, профили, цвета) | 10 | `Catalog_ФУРН_*` — справочники конфигуратора окон | нет (справочники, не регистраторы) |
| **ТОК** (расширение) | 7 | регистр продаж менеджеров + 3 константы + 2 регистра сведений | нет |
| **Настройки выписки** | 2 | `Catalog_НастройкиВыписки` + табличная часть шаблонов | нет |
| **Переработка ТМЦ** | 8 | акты переработки переданных/полученных + табличные части | нет |
| **Доверенность** | 2 | документ + номенклатура | нет |
| **Распределение косвенных затрат** | 5 | документ + 4 табличные части | нет |
| **Таможня (экспорт)** | 2 | `Document_ТаможеннаяДекларацияНаЭкспорт` + выплаты | нет (близкий `Document_ТаможеннаяДекларация` **доехал**, 58 338 движений — это **другой** тип) |
| **итого** | **35** | | **0** |

**Чем отвечаем до открытия прав:** по этим доменам **не** из регистров —
данных регистраторов с такими `Recorder_Type` в витрине нет. Бот не может
пересказать шапки закрытых документов и строки закрытых справочников ФУРН/ТОК;
константы ТОК (лимит, отсрочка, обмен с сайтом) в ответах недоступны.

**Действие одно** (при любом подтипе 401): **пере-прогон шага 14 установщика**
на Windows okna при визите владельца. База **файловая** — текущий установщик
справляется, часть А не нужна (`PLAN_ORCHESTRATOR` B4). После открытия прав
агент дочитает **35** сущностей сам, без переустановки (механика проверена на
klient-1, 38 дочитанных).

Поимённый список всех 35 — [`completeness-okna/skipped.txt`](completeness-okna/skipped.txt).

## 5. Что доедет само

Без действий с нашей стороны:

- **Дельты** — каждый такт (~38 с, B1). Всё, что открыто читателю, пополняется.
- **Пустые 415** — агент перечитывает каждым тактом; появятся строки —
  приедут. Список [`empty.txt`](completeness-okna/empty.txt).
- **Закрытые 35** — после шага 14 на Windows. До визита — см. §4 (компенсации
  регистрами нет).

Сверка контура в приёмнике (`packet_apply._check_contour_arrived`, коммит
`a8dfbf6`): журнал apply пишет «контур / НЕ В ВИТРИНЕ»; пустую сущность от
закрытой приёмник сам не отличает.
