## Цель (контракт этой части)

**Данные ВСЕ. Поиск по ВСЕМ. Ничего не упустить молча.**

Полнота доказывается числом, не ощущением:

- баланс контура до единицы: контур = доехало + закрыто + пустые − дочитанные;
- сверка «прислано против легло» — пусто;
- **реальная потеря** = закрытые минус перекрытые доехавшими сёстрами
  (`_RecordType`-пары, проекции) — остаток поимённо;
- поиск по всему: корпус+векторы по полной витрине; закрытые домены отвечают
  по регистрам с честным источником «по движениям» (форму держит код);
- приёмка — линейка п. 21 `TARGET.md` числом, хвост виден процентом.

## Без Windows: честный расклад (17.08)

Механика прав по коду `windows/odata-setup/src/ai-ext.ps1`:

- роль `AIReadAll` генерируется на объекты, перечисленные **в момент
  установки** (`:327-330`); новые объекты конфигурации ею не покрыты;
- назначение роли читателю делает **HTTP-сервис самоназначения** `AISetup`
  (`:374-399`): `GET /hs/ai-setup/setup` — назначает; `?check=<ПолноеИмя>` —
  `ПравоДоступа` по читателю; публикация через `default.vrd` (`:470-490`);
- загрузка расширения — только конфигуратором (COM / `LoadConfigFromFiles`).

**okna — без Windows можно.** Расширение стоит (база файловая, шаг 14
отработал). Зонд с юнита: `?check=` по закрытым сущностям классифицирует:
роль слетела → голый вызов setup назначает (Windows не нужен вовсе); объект
не покрыт (конфиг обновилась после установки) → перегенерация установщиком
(okna-5, заход владельца); RLS → решение админа в интерфейсе 1С, наш заход
тоже не нужен.

**klient-1 — полностью без Windows нельзя.** Расширение не загружено (шаг 14
молча пропущен на клиент-серверной); `.cfe` персонален под базу (реальные
UUID, `ai-ext.ps1:250`) — собирает установщик; СУБД в обход платформы
запрещена контрактом и недостижима; эскалация прав агентом недопустима.
Минимум — одна команда при заходе админа (~полгода, klient-1-7), дочитывание
само (проверено на 38). Всё остальное — без Windows: опись, корпус, словарь
регистров закрытых доменов, приёмка, мониторинг.
