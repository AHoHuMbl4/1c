in FROM clause`. То есть на первой базе **каждый счётный вопрос отвечал бы отказом при
наличии данных** — прямое нарушение п. 21.

Тот же класс проверки нужен КАЖДОМУ новому объекту, к которому обращается сервис: после
`alias_idx` и `search_entity_alias` первая база была проверена отдельно, и именно там
выяснилось, что права на алиасы не выданы вовсе (`HOW_NOT_TO §1.24`).

Причина шире одного случая: **`CREATE TABLE IF NOT EXISTS` у существующей таблицы не делает
ничего**, новая колонка в уже созданную базу из объявления не попадает. Поэтому добор стоит
`ALTER TABLE ... ADD COLUMN IF NOT EXISTS` в `corpus_init.sql` — в создании схемы, которое
идёт первым шагом каждого такта. Деградация плавная: пока база не пересобрана, карта пуста,
`coalesce(..., false)` читает это как «не папка», поведение совпадает с прежним.
