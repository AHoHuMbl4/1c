| Находка | Статус |
|---|---|

| Маршрутизация ломалась на другом языке: англоязычный вопрос давал 167 000 вместо 12 326 000 | ✅ закрыто: кандидаты из всей витрины |
| Фильтр «мусора» выбрасывал реальные идентификаторы (`INV000000021`, VIN, артикул, IBAN) | ✅ закрыто: версия записи отбрасывается по контракту `$metadata` |
| «Сумма = наибольшее число» — уже промахивалась на нашей базе | ✅ закрыто: колонку денег выбирает модель по именам из метаданных |

| Нижняя отсечка длины префикса убивала морфологию для CJK | ✅ закрыто: отсечки нет, а сам подбор заменён на `ts_levenshtein` |
| Русские промты и маркеры в `mcp_braine.py` | ✅ закрыто: описание инструмента на английском, тексты человека в окружении |
