достаточен** как доказательство «первая база цела»: лёгкий набор не покрывает

### Текущие FAIL (базлайн допускает только их; новый FAIL = стоп)

| Вопрос | Класс | Примечание |
|---|---|---|
| дай топ-3 товара за вчера | rank top-N | Золото считает по `Количество`, ответ пришёл в деньгах; правило меры поставлено, живьём ещё не сошлось |
| сколько позиций совсем не продаётся в этом месяце? | **K6** | Не та сущность (`SCORER_CLASSES` §4) |

| сколько клиентов реально покупают? | **K6** | Не та сущность |

K4 («эта неделя лучше прошлой или хуже?») на этом базлайне **OK** — закрыт
правкой формы сущности. K5a («сколько документов реализации за декабрь 2025?»)
**OK** (307). Улучшение (FAIL→OK) гейт пропускает; регресс (новый FAIL или
`pass` < 21 при полном наборе) — нет.

Оба **K6** упираются в один корень, замеренный 25.08: словарь синонимов не
связывает обиходные слова человека с сущностями базы
(`ts_lexize('search_dict_syn','клиент')` → `клиент`, связи с
`catalog_контрагенты` нет). Разбор — `docs/F6_SYNONYMS_FACTS.md`.

## Как гонять

```bash
# 1) полный скорер (живой контур; гейт его не вызывает)
AB_CONTOUR=okna ASK_URL=http://127.0.0.1:18092/ask \
  python3 ubuntu/serenedb/ab_scorer.py | tee /path/to/scorer-okna-last.txt

# либо jsonl: по строке на вопрос {"q":"...","verdict":"OK"|"FAIL",...}

# 2) оффлайн-сверка с базлайном
python3 ubuntu/serenedb/check_deploy_gate.py /path/to/scorer-okna-last.txt
# или: AB_MARK_DIR=/srv/1c и файл .claude/scorer-okna-last.{jsonl,txt}
```

Код выхода: **0** — набор ≥ базлайна по размеру, `pass` ≥ 20, нет FAIL вне
списка; **1** — иначе. Оффлайн-замок: `python3 ubuntu/serenedb/test_check_deploy_gate.py`.
