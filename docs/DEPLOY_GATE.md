## Как гонять

```bash
# 1) полный скорер (живой контур; гейт его не вызывает)
AB_CONTOUR=okna ASK_URL=http://127.0.0.1:18092/ask \
  python3 ubuntu/serenedb/ab_scorer.py | tee /path/to/scorer-okna-last.txt

# либо jsonl: по строке на вопрос {"q":"...","verdict":"OK"|"FAIL",...}

# 2) оффлайн-сверка с базлайном
python3 ubuntu/serenedb/check_deploy_gate.py /path/to/scorer-okna-last.txt
# или: AB_MARK_DIR=/srv/1c и файл .claude/scorer-okna-last.{jsonl,txt}
```

Код выхода: **0** — набор ≥ базлайна по размеру, `pass` ≥ 20, нет FAIL вне
списка; **1** — иначе. Оффлайн-замок: `python3 ubuntu/serenedb/test_check_deploy_gate.py`.
