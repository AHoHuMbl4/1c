### Критерий PASS на вопрос (compare)

- В ответе человеку видны **оба** периода с числами из ask_1c (не одно окно).
- Есть явный вердикт сравнения (больше / меньше / равно / неполное).
- Нет «выдуманной» разности, которой не было в тексте ни одного атома.
- `clarify` / `no_data` атома не замалчиваются.
