# Составной vs простой вопрос

Скилл включается только когда один вызов `ask_1c` не покрывает намерение
целиком **без** потери частей фразы.

## Составной (скилл)

| паттерн | пример | типичное разбитие |
|---------|--------|-------------------|
| два периода + сравнение | «в этом месяце продали больше, чем в прошлом?» | 2 атома (MTD, прошлый месяц), `synthesis=compare` |
| топ-N + величина по каждой | «дай топ-3 товара и сколько у каждого» | 1 атом на ранг **или** N атомов, если ядро не отдаёт список одним ответом; `synthesis=top_n` |
| несколько независимых срезов | «сколько продали вчера и сколько контрагентов в базе» | по атому на срез, `synthesis=table` |
| перечисление однотипных подсчётов | «остатки на складе А и на складе Б» | по атому на склад (формулировка — как спросил человек), `synthesis=table` |

## Простой (один ask_1c, скилл off)

| пример | почему |
|--------|--------|
| «сколько продали в этом месяце?» | один период, одна мера |
| «топ-5 товаров за неделю» | один rank-запрос, если формулировка уже простая |
| «сколько контрагентов?» | один подсчёт |

## Сомнительные случаи

- **Один rank-ответ уже содержит N строк** — предпочтителен один атом
  («топ-3 … за период»); декомпозиция на N+1 атомов не нужна.
- **Сравнение без двух явных периодов** («лучше, чем обычно») — скилл не
  додумывает период; либо уточнение человеку, либо один `ask_1c`, если
  формулировка самодостаточна.
- **Зависимые шаги** («кто лидер и сколько у него») — второй атом зависит
  от имени из первого; **вне** v1: нужен ответ первого атома перед вторым,
  но каждый атом остаётся простым вопросом без метаданных базы.

## Сознательно вне v1

- цепочки «сначала узнай имя, потом считай» (см. выше);
- составные вопросы с **общей** развилкой A/B/C на все атомы — каждый атом
  проходит свой контракт; скилл не сливает ветки;
- вопросы с календарём/гео/валютой как осью (§7bis PLAN_ANSWER_CONTRACT) —
  пока ось не в ядре, декомпозиция не подменяет ось;
- NL-графики, отчёты `report_1c`, вики-only ответы;
- пересчёт долей, процентов, «на сколько больше в процентах» — новое число,
  не форматирование;
- автоматический выбор `focus` / `measure` по словарям или именам таблиц.
