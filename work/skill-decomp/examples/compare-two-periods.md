# Пример: сравнение двух периодов

**Вопрос человека:** «В этом месяце продали больше, чем в прошлом?»

## План разбития

```json
{
  "composite": true,
  "synthesis": "compare",
  "atoms": [
    {
      "id": "mtd",
      "question": "сколько продали в этом месяце?",
      "label": "этот месяц"
    },
    {
      "id": "prev",
      "question": "сколько продали в прошлом месяце?",
      "label": "прошлый месяц"
    }
  ],
  "compare": {
    "left_id": "mtd",
    "right_id": "prev",
    "relation": "more_than"
  }
}
```

## Вызовы

1. `ask_1c(question="сколько продали в этом месяце?")`
2. `ask_1c(question="сколько продали в прошлом месяце?")`

## Таблица (черновик)

| id | label | kind | body (фрагмент) |
|----|-------|------|-----------------|
| mtd | этот месяц | answer | … 1 234 567,89 … |
| prev | прошлый месяц | answer | … 987 654,32 … |

## Итог человеку (без разности)

«Да, больше: за этот месяц — 1 234 567,89; за прошлый месяц — 987 654,32.»

Вердикт «больше / меньше / равно» — по двум **готовым** числам из ответов
базы; отдельное сравнительное число (разность) не вводится.

Если `prev` → `clarify`: «За этот месяц — …; за прошлый месяц уточнение:
[текст OPTIONS]. Сравнение пока неполное.»
