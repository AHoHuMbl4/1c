# Пример: несколько независимых срезов

**Вопрос человека:** «Сколько продали вчера и сколько сейчас контрагентов в
базе?»

## План

```json
{
  "composite": true,
  "synthesis": "table",
  "atoms": [
    {
      "id": "sales",
      "question": "сколько продали вчера?",
      "label": "продажи за вчера"
    },
    {
      "id": "cnt",
      "question": "сколько контрагентов в базе?",
      "label": "контрагенты"
    }
  ]
}
```

## Итог

Две строки, два числа из двух ответов `ask_1c`. Связка «и» в исходной фразе —
повод для скилла; содержание — только таблица.
