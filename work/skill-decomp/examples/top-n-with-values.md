# Пример: топ-N и сколько у каждого

**Вопрос человека:** «Дай топ-3 товара за этот месяц и сколько продали по
каждому.»

## Вариант A — один rank-атом (предпочтительно, если формулировка простая)

```json
{
  "composite": true,
  "synthesis": "top_n",
  "atoms": [
    {
      "id": "rank",
      "question": "топ-3 товара по продажам за этот месяц с количеством по каждому",
      "label": "топ-3"
    }
  ]
}
```

Один `ask_1c`. Таблица — одна строка; итог — текст/rank-таблица из ответа
**без** дробления на три отдельных подсчёта.

## Вариант B — N атомов (если ядро не отдаёт список одним ответом)

После ответа с именами позиций (от человека или из первого rank-вызова) —
отдельный простой вопрос на каждую позицию:

```json
{
  "composite": true,
  "synthesis": "top_n",
  "atoms": [
    {
      "id": "p1",
      "question": "сколько продали <имя1> за этот месяц?",
      "label": "<имя1>"
    },
    {
      "id": "p2",
      "question": "сколько продали <имя2> за этот месяц?",
      "label": "<имя2>"
    },
    {
      "id": "p3",
      "question": "сколько продали <имя3> за этот месяц?",
      "label": "<имя3>"
    }
  ]
}
```

`<имяN>` — как в ответе базы или как назвал человек, **не** из списка таблиц
конфигурации.

## Итог человеку

| # | Товар | Продажи |
|---|-------|---------|
| 1 | … | … |
| 2 | … | clarify → «нужно уточнение: …» |
| 3 | … | нет данных |

Строка 2 не замалчивается ради «красивого» топ-3.
