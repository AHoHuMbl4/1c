## Ловушки стенда (выучено в этой сессии)

- .cmd через ssh: только CP866 (iconv), кириллица в /N иначе ломается.
- .ps1 через scp: UTF-8 **с BOM** обязателен.
- powershell -Command через cmd-ssh рвётся о кавычки/кириллицу — только -File.
- `set VAR=значение && ...` в cmd: пробел перед && попадает в значение.
- В COM late-bound свойства квалификаторов — только англ. имена; глобальные
  методы $ib — англ. (String, ValueToStringInternal); Вычислить/Evaluate нет.
- Метаданные через COM: Владельцы справочника — пустая коллекция (баг/лимит
  8.3.27); Графы.Ссылки — читаются, но ПутьКДанным нет; РегистрируемыеДокументы
  журнала читаются; Периодичность РС = «ПериодичностьРегистраСведений».
