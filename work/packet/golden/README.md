# Golden-проба формата CSV агента пакетного транспорта

Проверяет **К5** (`docs/PACKET_CONTRACT.md` §7): CSV, который пишет `packet-agent.exe`
(C#, Windows), обязан быть **байт-в-байт** тем же, что пишет `poc_load_entity.py`
(Python, Ubuntu) из того же ответа OData. До зелёной пробы агент в бой не выкатывается.

## Состав

- `fixtures/<entity>.page1.json` — **сырые** ответы живого OData (байты как пришли,
  `$format=json&$top=10000&$inlinecount=allpages`), сняты 06.08 со стенда через шлюз
  `http://127.0.0.1:6011`;
- `fixtures/metadata.xml` — снимок `$metadata` того же момента; разворот вложенных
  наборов (`_flatten_nested`) и `declared_key` обязаны разбирать один и тот же текст
  на обеих сторонах;
- `make_reference.py` — эталон: прогон фикстур через `_flatten_nested`, `_cell`,
  `safe_col`, `csv.writer` из `ubuntu/serenedb/poc_load_entity.py`;
- `reference/<entity>.csv` — сгенерированные эталоны (коммитятся);
- `probe.cmd` — прогон на Windows; `out\` — вывод агента (в .gitignore);
- `_Synthetic_*` — синтетические страницы (не со стенда): имя начинается с `_`,
  сущности нет в `metadata.xml`, обе стороны разворачивают её с `entity_set=None`.

## Фикстуры (почему выбраны)

| Сущность | Строк | Что покрывает |
|---|---|---|
| `Catalog_Справки2ЕГАИС` | 1 | булевы `true/false`, дата-время `T`→пробел (`0001-01-01 00:00:00`), unicode, пустые/нулевые поля |
| `Catalog_ШаблоныПоясненийДляФНС` | 3 из 35 | переводы строк внутри строк (CSV-quoting), запятые, длинные значения. Все 35 строк были с переводами — взяты первые 3, фикстура урезана ради размера диффа (06.08) |
| `Catalog_СпособыОтраженияРасходовПоАмортизации` | 3 | вложенная табличная часть (`_flatten_nested` по `metadata.xml`): шапка + поля строк, составные ссылки `*_Type` |
| `_Synthetic_КаверзныеЗначения` | 2 | **синтетическая** (сущности нет в `metadata.xml`, flatten отключён — как `entity_set=None` в poc): кавычки с удвоением, `\n` и `\r\n` внутри поля, float-формы Python (`0.1`, `5.0`, `100.0`), bigint, null→пусто, дата с долями секунд (regex не срабатывает), emoji в имени колонки (`safe_col` по кодпоинтам), union колонок по двум строкам |

Кавычки `"` внутри значений: поиском по ВСЕМ мелким сущностям боевой базы (4585 имён,
замер 06.08) не нашлось ни одной — поэтому правило удвоения кавычек закрывает
синтетическая фикстура, а не живая. При появлении живой сущности с кавычками её
следует добавить сюда.

## Как прогонять

1. Обновить эталоны (на Ubuntu, рядом со стендом):
   `python3 make_reference.py` — пересоздаёт `reference/*.csv` из `fixtures/`.
2. На Windows: собрать агент (`windows\packet-agent\build.cmd`), затем
   `probe.cmd` (или `probe.cmd C:\путь\packet-agent.exe`).
3. Код выхода: `0` — все CSV совпали побайтно; `1` — есть расхождение.

## При расхождении

Это дефект **формата** (К5), а не данных: агент обязан воспроизводить семантику
`poc_load_entity.py` точно — булевы строчными, дату с пробелом, диалект Python csv
(quote `"`, удвоение, CRLF), header после `safe_col`, UTF-8 без BOM. Чинить агент,
а не эталон: источник истины — Python-версия, уже проверенная витриной.
