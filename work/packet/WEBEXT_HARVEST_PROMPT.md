# Задание: собрать компонент «Расширение веб-сервера» 1С из имеющихся дистрибутивов

## Контекст (читать целиком, всё нужное здесь)

Строится хранилище маленьких файлов, которое будет раздавать установщик нашего продукта:
у части клиентов платформа 1С установлена БЕЗ компонента «Модули расширения веб-сервера»,
и без этих файлов не работает публикация базы в IIS. Нужные файлы — это 2-4 штуки на
версию платформы, весом сотни КБ (не целые дистрибутивы).

На сетевом диске `\\192.168.7.10\s3` лежат скачанные дистрибутивы платформы 1С:Предприятие 8.3
(почти все версии). Структура заранее неизвестна: могут быть папки по версиям, внутри —
`1CEnterprise 8.msi`, `1CEnterprise 8 (x86-64).msi`, `setup.exe`, rar/zip-архивы или
уже распакованные каталоги.

## Задача

Для каждой версии платформы и каждой разрядности (x86 и x86-64), которые найдутся в
дистрибутивах, извлечь файлы веб-расширения и разложить их в хранилище на том же диске.

Извлекаемые файлы (из `bin` дистрибутива):
- `wsisapi.dll`       (обязателен)
- `webinst.exe`       (обязателен)
- `webinst_*.res`     (все, какие есть: webinst_root.res, webinst_ru.res и т.п.)

## Способ извлечения — ТОЛЬКО административная установка (без установки платформы!)

НИЧЕГО не устанавливать на машину. Не трогать уже установленные платформы 1С.
Штатный способ достать файлы из MSI без установки — administrative install:

    msiexec /a "<путь>\1CEnterprise 8.msi" /qn TARGETDIR="<временный каталог>"

Это просто распаковывает содержимое MSI в TARGETDIR (никакой регистрации, служб, реестра).
После распаковки файлы лежат в `<временный каталог>\...\bin\` — забрать нужные,
временный каталог удалить.

Если дистрибутив — архив (rar/zip): сначала распаковать во временный каталог
(7-Zip: `7z x`), найти внутри MSI, дальше по схеме выше.
Если рядом только `setup.exe` — поискать MSI рядом или во вложенных папках дистрибутива.

## Разметка результата

Кладём на тот же диск:

    \\192.168.7.10\s3\webext\<версия>\<разрядность>\wsisapi.dll
    \\192.168.7.10\s3\webext\<версия>\<разрядность>\webinst.exe
    \\192.168.7.10\s3\webext\<версия>\<разрядность>\webinst_*.res

`<версия>` — точный билд вида `8.3.27.1786` (брать из ProductVersion MSI, НЕ из имени папки).
`<разрядность>` — `x86` или `x64` (по MSI: `1CEnterprise 8 (x86-64).msi` = x64,
`1CEnterprise 8.msi` = x86; при сомнении — по свойству MSI или разрядности файлов).

ProductVersion читать штатным COM Windows Installer (PowerShell):

    $wi = New-Object -ComObject WindowsInstaller.Installer
    $db = $wi.GetType().InvokeMember('OpenDatabase','InvokeMethod',$null,$wi,@($msi,0))
    $v = $db.GetType().InvokeMember('OpenView','InvokeMethod',$null,$db,@("SELECT ``Value`` FROM ``Property`` WHERE ``Property``='ProductVersion'"))
    $v.GetType().InvokeMember('Execute','InvokeMethod',$null,$v,@()) | Out-Null
    $r = $v.GetType().InvokeMember('Fetch','InvokeMethod',$null,$v,@())
    $r.GetType().InvokeMember('StringData','GetProperty',$null,$r,@(1))

## Манифест

После сбора — `\\192.168.7.10\s3\webext\index.tsv` (UTF-8, табуляция), одна строка на ячейку:

    версия<TAB>разрядность<TAB>sha256 wsisapi.dll<TAB>sha256 webinst.exe<TAB>путь к исходному MSI

Идемпотентность: ячейки, которые уже есть в хранилище (и совпадают по sha256 с источником),
не пересобирать — пропускать с отметкой в логе.

## Проверки (каждая ячейка)

- `wsisapi.dll` и `webinst.exe` присутствуют, ненулевого размера;
- контрольная: `wsisapi.dll` — PE-файл, в импортах есть `core83.dll` (быстрая проверка
  строки в бинарнике первых 4 КБ импорт-таблицы или pefile); если нет — ячейка подозрительная,
  в отчёт с пометкой, но всё равно выложить;
- sha256 обоих файлов посчитан и записан в манифест.

## Границы и краевые случаи

- Ничего не устанавливать, не менять реестр, не трогать установленные платформы 1С.
  Временные каталоги — только в %TEMP%, удалять за собой.
- Версии старше 8.3.5 могут не иметь этого компонента вовсе — фиксировать пропуском в отчёте,
  не ошибкой.
- Дистрибутив без MSI (только setup.exe без видимого MSI) — пропуск с пометкой в отчёте.
- Ошибка на одной версии НЕ останавливает сбор остальных — пишем в отчёт и идём дальше.
- Никаких скачиваний из интернета — работаем только с тем, что лежит в \\192.168.7.10\s3.

## Отчёт (финальный, обязателен)

1. Таблица: версия × разрядность → OK / пропуск (причина) / ошибка (текст).
2. Сколько ячеек собрано, сколько пропущено, общий вес хранилища.
3. Путь к манифесту и логу.
4. Список версий, для которых веб-расширение НЕ нашлось (это важно знать).
