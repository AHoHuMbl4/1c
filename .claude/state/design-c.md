src известен ∧ span DL-хитит хвост/label src → группа ИСКЛЮЧАЕТСЯ (понятие (iii)),
SUPERSEDE/match-expr для неё ЗАПРЕЩЁН (сужение строк по имени сущности = п.13). В probe (z06:43–145), ДО resolve_values; триггер: (>=1
UNMATCHED) ∨ (у покрытой группы hit только fuzzy/part). 🔴 SUPERSEDE: span перезаписывает
exprs покрытых групп с hit ∈ {unmatched, fuzzy, part}; exact/slop НЕ трогаются
