## 3. C4 — норм-функция имён на входе probe (детерминированная, без LLM)

Точка: `z06.probe` (z06:43–145). Для группы-альтернативы с пробелами, ТОЛЬКО когда
exact/slop/fuzzy/part на исходной форме дали 0 (fallback-принцип `resolve_values`,
z06:107–109): норм-вариант — склейка слов + lower (единая функция класса
`_homonym_norm`, z21:831 — переиспользуем, вторых копий не заводим) с гардинами:
- минимальная длина склейки ≥8 символов (короткие склейки — ложные матчи);
- `ts_levenshtein(склейка, min(2, len//4))` — лечит падеж («реализациитмц» → dist 1
  до «реализациятмц» при пороге 2); `ts_like('%склейка%')` — для баз с точной
  склейкой (терминные функции — образец в нижнем регистре, как z06:51–53);
- ранг ниже exact (замок «norm не вытесняет exact»);
- diag-тег «norm» — int-ключ группы, `matched_group_count` честен (z06:144–158).

Граница: term-probe смерть остаётся честным no_data для значений, которых в базе нет
(после норм-варианта и `resolve_values`).
