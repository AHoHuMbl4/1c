# Линза-2 (волна C «один путь»): интент и словарь — карта мест смерти вопроса

Ты — аналитик проекта /srv/1c (бот-ассистент по 1С: вопрос → интент → словарь/поиск
сущностей и мер → меню прочтений при >1 → ответ). Режим: ТОЛЬКО ЧТЕНИЕ кода. Ничего
не править, в git не фиксировать, коммитов нет. Единственный артефакт — файл-реестр
`.claude/state/c-lens2-intent.md` (Write в конце работы).

## Контекст дефекта

Контракт «один путь»: любое >1 прочтение → меню, ровно одно → сразу ответ; отказ
законен ТОЛЬКО если данных реально нет. Прогон 67 вопросов: wrong 0, но 6 умерли
отказом при живых данных. Твои четыре — класс «редкое слово»: вопрос называет
знакомое понятие незнакомым слову словаря:

- «а на прошлой неделе сколько наторговали» — эталон 357 393,03
- «а сколько наторговали в воскресенье» — эталон 0,00 (живой ноль)
- «сегодня сколько уже наотгружали» — эталон 661 458,38
- «сколько за этот месяц уже вышло» — эталон 2 083 550,46

«наторговали»/«наотгружали»/«вышло» — синонимы выручки/отгрузки, но словарю
незнакомы. Вопрос умирает ДО меню и ДО ответа. Найди, ГДЕ именно.

## Что извлечь (факты с file:line, цитаты короткие, без догадок)

1. Пайплайн интента: как из сырого вопроса получаются слоты (want/compute, слова
   меры, слова сущности, период). Какие LLM-вызовы есть в тракте (z01: какие модели,
   какие промты, какие бюджеты/таймауты, fail-soft или блокирующие).
2. Матчинг слов со словарём: exact/alias/stem — функции, file:line; что происходит
   со словом, которого нет в словаре: оно игнорируется молча? вопрос продолжает путь
   без меры/сущности? где тогда умирает (какой return и в каком файле)?
3. Для конкретных четырёх слов: проследи по коду путь вопроса без словарного хита —
   до какого исхода он доезжает (no_data? пустое меню? отказ?) — цепочка file:line.
4. Словарные таблицы: какие (search_dict, search_dict_syn, алиасы вики), как
   конфигурируются (env), где читаются. Известная аномалия: ASK_SOLR_SYNONYMS_DICT
   указывает на отсутствующую таблицу — найди в коде, что происходит при её
   отсутствии (молчание? ошибка? деградация?), file:line.
5. Есть ли в z01/z02 механизм, который МОГ бы отдать «незнакомое слово + пул
   кандидатов» наружу (журнал, diag) — или слово пропадает бесследно.

## Формат реестра c-lens2-intent.md

- §1 пайплайн интента (слоты, LLM-вызовы с бюджетами, file:line);
- §2 таблица «точек смерти» для незнакомого слова: file:line → механизм → условие;
- §3 цепочка смерти для «наторговали» (по шагам, file:line);
- §4 словарные таблицы и конфиг (env-имена, таблицы, что при отсутствии);
- §5 точки, где доступен полный контекст (вопрос + пул кандидатов словаря с их
  описаниями/алиасами), чтобы отдать LLM-резолверу «где что».

Только измеримое: каждая строка реестра обязана иметь file:line. Мнений «наверное» —
не писать; если что-то не нашёл — так и написать «не найдено».
